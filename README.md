SUM,COUNT and AVERAGE Functions- calculated the total price of all products in the dataset, found out the number of products in the dataset, calculated the average price of all products.
MIN and MAX Functions- Determined the minimum price among all products, Found out maximum price among all products.
IF Function- Created a new column named Price Range, Categorized products with a price greater than or equal to 500 as "High Price", categorized other products as "Standard Price".
SUM IF and COUNT IF function- Calculated the total price of products in the Electronics category using SUMIF, Counted the products with a price less than 100 using COUNTIF.
Text Formatting - LEFT, RIGHT, and MID :- Created a new column named Day using the first 2 characters of Product ID with LEFT, Created a new column named Country Code using the last 2 characters of Product ID with RIGHT, Created a new column named Month by extracting the 4th to 6th characters of Product ID using MID.
